# ボロノイ図インタラクティブアニメーター

種点をクリックまたはドラッグで配置し、ロイド緩和アルゴリズムによる均質化アニメーションをリアルタイムで観察できるボロノイ図ツールです。

## 機能
- クリックで種点を追加・ドラッグで移動
- ロイド緩和アルゴリズムによる自動均質化アニメーション
- 距離関数の切り替え（ユークリッド距離・マンハッタン距離・チェビシェフ距離）
- カラーリングモードの変更と画像保存

## 使い方
ブラウザで開き、キャンバス上をクリックして種点を配置するとボロノイ領域が即座に描画されます。「緩和」ボタンを押すと種点が自動的に均等配置へ収束するアニメーションが始まります。
